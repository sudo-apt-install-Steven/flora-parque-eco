# Diretório de Imagens Botânicas — Parque Ecológico Vilhena

Coloque as fotos das árvores coletadas em campo nas pastas correspondentes a cada grupo de trabalho:

- `public/trees/grupo-a/` -> Fotos das árvores do **Grupo A** (Região Noroeste / Gramado Oeste)
- `public/trees/grupo-b/` -> Fotos das árvores do **Grupo B** (Região Nordeste / Parquinho e Gramado Leste)
- `public/trees/grupo-c/` -> Fotos das árvores do **Grupo C** (Região Sul / Trilha e Margem do Lago)

## Padrão de Nomenclatura Recomendado (Opcional)
Para melhor organização anatômica das imagens:
- `arvore-01-inteira.jpg` (visão geral do indivíduo)
- `arvore-01-folha.jpg` (detalhe dos ramos / folhas)
- `arvore-01-casca.jpg` (detalhe do tronco / ritidoma)
- `arvore-01-fruto.jpg` ou `arvore-01-flor.jpg` (estruturas reprodutivas)

O sistema carrega automaticamente as imagens locais e disponibiliza visualizador em alta resolução com zoom e galeria completa.
